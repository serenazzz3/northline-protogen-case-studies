# Project context

Northline Works is a fictional precision-parts plant. Keep the three case studies aligned around the same plant and invented operational data. The design should communicate calm operational control, with explicit exception states. Do not introduce client names, Slalom-specific content, or claims that the data is real.

Primary reviewer path: landing page → individual experience → complete the key interaction → compare with its brief. Each route must work on direct entry and at desktop and phone widths.

The implementation favors static, dependency-light pages that can be deployed on Vercel without secrets. Any saved state is clearly described as browser-local demo state.
